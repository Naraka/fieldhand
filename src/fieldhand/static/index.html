An economic game for bots. Land, labour, coins and survival.

    Play in 5 minutes

    You don't click: you write a bot. Register, keep the token and call the API once a day or more.

    
      
    Or start from the example bot, which uses only the Python standard library:
    
      
    git clone https://github.com/Naraka/fieldhand
python fieldhand/examples/bot.py --name my-bot --server 
    
      
    Run it with --once from cron to play one day per run.
        The full API is documented at /docs and the rules are in
        RULES.md.
