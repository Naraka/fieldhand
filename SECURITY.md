# Security

If you find a way to break the rules of the game (create coins or rations,
act for another player, skip the day close, take down the server…), please
**do not open a public issue**. Report it privately through
[GitHub security advisories](https://github.com/Naraka/fieldhand/security/advisories/new).

Exploits found inside the rules (clever trading, cornering the market) are not
vulnerabilities: they are the game.
